## 尺度与构造

建筑基准地面绝对 Z = 6.90 m，铺地顶 Z = 7.04 m。

- A 外部包围盒约 31.069 × 30.936 m；最高点比地面高 22.01 m。占用层标高相对地面为 0.14 / 6.0 / 11.6 / 16.6 m，上部退台屋面约 20.75 m；底层较高用于商业入口。
- B 外部包围盒约 40.020 × 36.402 m；最高点比地面高 28.00 m。层标高为 0.14 / 6.0 / 11.6 / 16.6 / 21.6 m，屋面约 26.6 m。
- 连桥楼面绝对 Z = 18.50 m，与 A/B 对应楼板同标高；中段宽 5.4 m，端部渐宽至 8.4 m。最低腹板距铺地约 10.16 m。两段三次曲线保持切线连续；采样最小曲率半径 4.860 m，大于对应半桥宽 2.700 m，未检出原先发生的平面内侧折返。
- 玻璃使用明确分片与 45 mm 实体厚度，外侧竖梃宽 65 mm、深 160 mm；648 块 A/B 玻璃已消除四角扭曲并重算法线，最大平面修正约 20.93 mm。横向白色围带有正面、顶返和底返，入口有真实玻璃缺口、门扇、深门套与室内遮挡。
- 办公试片约 9.54 × 4.875 × 11.14 m，三层、层高 3.6 m，正面玻璃模块 1.5 m，包含实体楼板、窗间墙、转角框、玻璃、室内背板与百叶。不是整栋 B07 改造；默认窗景隐藏该试片。

研究范围仍是约 46×120 m 的旧样板坐标包围区，不是已测绘地块红线。B 围带西端 X 约 −68.060 m，比研究矩形 −68 m 多出约 60 mm；后续真实地图试摆需核对退界。中庭与门厅只做窗景可见空间，并非完整可运营室内、结构或无障碍设计。

## 相机与坐标

固定窗景保持 Blender 位置 `(26, -42, 37)` m、目标 `(-22, 115, 19)` m、垂直 FOV 54°、画幅 16:9。坐标约定：UE 厘米 = `(100*BlenderX, -100*BlenderY, 100*BlenderZ)`。glTF 导出按 Y-up 标准，节点单位为米；不要对 GLB 再重复一次轴交换。FBX 使用 Blender 的 −Z forward / Y up 和单位换算；UE 首次导入仍需用尺寸实测确认实际导入设置。
