## 参数依据

[容柏生结构设计事务所设计者论文《珠海某项目大底盘双塔超限高层结构设计》](https://pdf.hanspub.org/hjce20170600000_33611064.pdf)，PDF第2页，五层商业裙房层高为6.0、5.5、5.75、5.5、5.5米，主屋面28.25米；同项目办公主层高4.2米、公寓3.3米。此次选择首层6.0、标准5.5，源于具体商业工程实例，不是强制标准或该工程复刻。

[Galaxy SOHO运营方B01商铺](https://www.sohochinaoffice.com/room/70915?lang=zch)列标准层高5.4米，但它只证明该商业单元，不能推称所有商业层同高。[ZHA官方](https://www.zha.com/projects/architecture/galaxy-soho)明确下三层商业娱乐、上部办公、顶部餐饮；官方现页面没有逐层尺寸表。已实际查看署名ZHA的公开剖面，商业间距更大、桥与楼板齐标高，但没有可读尺寸标尺，未从像素推算精确米数。

更多来源与适用范围见 `commercial_height_evidence.json`。本候选是沿已确认Galaxy方向设计的商业组合，不是Galaxy整栋混合用途楼的尺寸复刻。没有另设无依据的“餐饮统一层高”。

## 细部与建筑关系

门扇顶仍位于楼面以上2.78米，实际玻璃面板2.76米（下留20毫米缝）；把手、框料、柜台和家具保持人尺度。普通白带截面仍0.89米，玻璃厚度/金属框截面未按高度比例放大。新增首层上部玻璃分格，内厅背板及B入口吊顶局部提高，填足6米商业层空间。退台移到新楼面，补1.10米总高露台护边，屋面屏风保持原构件高度而重新定位。

桥面实体上表面为绝对18.54米，精确对齐A/B第三个商业楼面（L2）；桥下最低净空10.96米。桥舱净高度设计3.65米、顶檐最高3.95米，桥宽中间4.40/端部6.20米，都保持原尺寸。桥面消除了原参考标高上方12厘米偏差，没有跟商场层高整体变厚。

办公导出GLB的几何/属性BIN块与03逐字节完全一致，其余JSON只差三个网格名称后缀；整个文件SHA因此不同。可见办公造型、物理尺度和材质候选保留，不把办公层数或高度改小来衬大商场。背景只用于固定窗景参照，尚未做原City地图里的红线、相邻碰撞或运行时验证。

## 截图中的比例

只对同一固定相机实图比较。在1280×720小样中，A层距从56–59增至75–81像素、玻璃从45–47增至61–66；B层距从30–33增至39–42、玻璃从23–25增至32–34。白带仍A12–15/B6–8像素，占层距约16–20%，没有放粗。A/B屋顶约上移70–80/45–50像素，桥舱仍45–48像素。最终图每轴2倍，数值按2倍换算。
