# 天气天空与城市远景补完

2026-09-24，在现代都市版本上修复雨天天空和动态云，并补齐天际线下方的裸地缺口。

## 渲染与天气

- 复用 UE 5.7 原生体积云和时间重建。均衡档使用 0.5 倍主视线采样、低成本反射采样；云影贴图为 256×256，覆盖相机周围 8 km。
- 云层布局周期固定为 32 km。晴天云底 2.2 km、厚度 2.5 km；降雨时平滑过渡到云底 1.2 km、厚度 3.5 km，同时增加覆盖率、密度和雨层云混合。大气散射在地图原始系数上按比例调整。
- 云影参与建筑和道路照明；雨天天空、路面反射、直射光强度和雾相互匹配。关闭了材质自带的闪电发光。
- 云层布局使用天气风速的累计位移，单位为米/秒，再转换为云布局 UV。风向变化不会重算累计时间的乘数，时钟滑块也不会移动云。噪声风保持固定，提供轻微形变；偏移不在一个周期处回绕，避免长时间运行跳位。
- 本次修改位于共享天气控制器，所有场景使用相同联动；独立窗框的样式和选择逻辑保持原有接口。

## 远景覆盖

保留原相机、16 栋近楼、18 座远塔及16辆车。新增18栋中低层楼体，合并为四组；另一个网格提供远处 T 字路口和广场。新增 9,372 三角形，建筑组总计 94,792 三角形、51 网格、194 材质段。City 地图现为 137 个 Actor。

生成脚本检查固定相机的30条地面视线；地图审计独立验证五个新增网格的数量、位置、包围盒与源 GLB 哈希。实机复核确认大道尽头和塔楼根部形成连续街区，仍保留上部天空视野。

## 复测

`Scripts/validate.ps1` 已增加云渲染、天气参数和累计位移检查，并拒绝过期截图、截图超时或缺帧。`city-cloudmotion` 生成16帧、每帧间隔2秒，可比较至少30秒的云层变化。正式包使用以下命令复测：

```powershell
.\unreal\Scripts\validate.ps1 -EngineRoot 'D:\Epic\Epic Games\UE_5.7' -Packaged -Cases 'city-cloudmotion,city-rainnight,alley-rain' -CaptureSeconds 20 -FrameStyle graphite
```

旧版 `city-modern-verification.json` 保留为天气补完前的历史记录，不能替代本轮的最终包测量。材质参数名和单位以本地 UE 5.7 资产反射及表达式为准；参考 [UE 官方体积云材质说明](https://dev.epicgames.com/documentation/en-us/unreal-engine/volumetric-cloud-material-in-unreal-engine?application_version=5.7)。

## 正式包结果

同机 RTX 5060 / i5-14600K，1280×820、均衡档85%内部渲染、Lumen开启。晴雨均运行30秒，排除前2秒，关闭VSync和帧率上限，隐藏窗框以比较场景本身。

| 天气 | 改前平均 / P95 (ms) | 改后平均 / P95 (ms) | 改后折算FPS |
| --- | ---: | ---: | ---: |
| 晴天 | 5.54 / 6.57 | 5.64 / 6.84 | 177.3 |
| 雨天 | 6.16 / 7.79 | 5.73 / 6.94 | 174.6 |

晴天平均帧耗基本持平，雨天本次短测略快；这是整版效果与几何变化的比较，不能据此宣称体积云没有成本。指标是应用帧间隔，不是GPU计时或长期性能保证。

体积云开启/关闭对照在纯天空区域的平均像素差为 15.47/255；同天气固定时刻的16帧覆盖 30.16 秒，首尾纯天空区域差为 0.93/255，已结合图像复核云形移动。雨夜、后巷雨天和窗框检查通过，最终日志无ensure或材质回退。
