## 构图与素材

- 相机位于道路右侧楼内，距路面约 30 m，斜望沿街建筑及远景天际线。位置为 UE 厘米 `(2600, 4200, 3700)`，目标点 `(-2200, -11500, 1900)`，垂直视角 54°。
- 原创现代建筑组含 16 栋近景建筑、18 栋远景塔楼、18 栋中远景楼体和 12 根 LED 灯杆。中远景楼体合为四组，另有远处路口，遮住道路尽头和塔楼根部的裸地。使用幕墙分格、退台、竖向遮阳构件、石材楼带和屋顶设备遮挡。
- 保留 16 辆动态车流；车模更换为有车窗、轮拱、轮胎和灯具的 916 三角形轿车，提供四色车漆。运动沿用原有双向道路循环。
- 28 棵写实椴树提取自项目已有的 NVIDIA ORCA / Amazon Lumberyard Bistro 资源，以一个实例组件保存。来源、CC BY 4.0 许可与修改说明见 `Art/City/README.md` 和根目录 `THIRD_PARTY_ASSETS.md`。
- 新增建筑、车辆和树木使用 Nanite；共享材质，关闭树木碰撞及顶点风动画，6 盏路灯不投射动态阴影。保存地图为 137 个 Actor。

## 窗框协作约定

City 地图只保存楼外景观与相机，不放置观察者的窗框或窗台。独立的 `AWindowFrame` 跟随活动相机，根据当前视口调整构图。切换场景时保留当前会话的窗框选择。

现有款式 ID 为 `oak`、`ivory`、`graphite`，可通过界面或 `OOWFrame graphite` 替换；启动参数为 `-OOWFrame=graphite`。这些 ID 可作为未来收藏物品的稳定引用，避免将款式绑定到场景地图。当前实现提供三种外观，不包含解锁条件、挂机收益或跨启动存档。

## 复建与检查

建筑与车模分别由 `Scripts/prepare_modern_city.mjs`、`Scripts/prepare_city_vehicle.mjs` 生成；树木提取脚本为 `Scripts/prepare_city_assets.py`。常规 `Run-Unreal.ps1 -Mode Import` 已在基础材质导入之后、运行时窗框资源生成之前执行 `Scripts/build_city_lookdev.py`。

通过 UE Python 命令行运行 `Scripts/audit_city_lookdev.py`，独立重新加载已保存的 City 地图，检查相机、16 辆车的方向/尺寸/标签、建筑数量、28 个树实例的世界变换、材质用途、Nanite 与未烘入窗框。结果保存在 `city-modern-audit.json`，当前通过。

材质采用适合楼侧远观的反射 PBR 近似，建筑没有参考图中的完整室内空间；植被风动画也未包含在此次重构中。性能结果必须以正式包同机实测为准，不能由 Actor 数量直接推算帧率。

## 首轮正式包验证（天气补完前的历史记录）

Windows 11、i5-14600K、RTX 5060，同机单个项目进程，1280×820，均衡档、85% 内部渲染比例，Lumen 硬件光追和反射开启。旧、新都市均固定晴天 16:30、关闭帧率上限和 VSync、不显示装饰窗框，运行 35 秒并排除最初 2 秒。

| 指标 | 旧都市 | 现代都市 |
| --- | ---: | ---: |
| 平均帧间隔 | 7.88 ms | 5.79 ms |
| P95 帧间隔 | 9.78 ms | 7.10 ms |
| 平均间隔折算 FPS | 126.9 | 172.8 |

此次整版改造短测 FPS 提高约 36.2%，平均帧间隔减少 26.6%。相机、布景和网格组织均有变化，不能把收益全部归因于某一项优化。以上为应用帧间隔，不是 GPU timer，也不是长时间或原生桌面分辨率保证。

最终包另通过带石墨色窗框的正午三帧车流检查及 23 点雨夜检查。16 辆车持续运动，窗框独立存在；最终测试日志没有材质回退或 ensure。首次带窗框验证发现的运行时网格 UV 流送初始化问题，已与窗框任务协作修复并在最终包复测。
