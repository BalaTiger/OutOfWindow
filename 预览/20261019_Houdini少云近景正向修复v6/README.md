# 少云近景：v6 正向局部形体实验
本轮结论：拓扑门禁通过，视觉未通过；未接入默认云。
一个128³样本，原控制密度逐体素保留，受保护B区零差异。新增四条不等尺度/方向的连续支脊，只有正向添加，没有整体拉伸、冠头复制或事后删除碎片。
先检查原/控制/候选连通性和相机透明度投影，再保存Houdini工程并仅渲染新candidate。original/control EXR按相同密度、相机、灯光、材质和采样参数复用。控制和候选共用同一物理网格；原网格比较含重采样影响。
密度积分增加1.8689%；1e-4和0.02阈值均为单个连通体，边界三层密度为0。实际渲染轮廓IoU为0.980397。
视觉仍有直立左壁、平底折角、三组相似平滑冠头；新增局部形成小钩和突刺。不能将连通通过解释为自然度通过。
