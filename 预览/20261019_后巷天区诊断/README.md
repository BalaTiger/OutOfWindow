# 后巷可见天区与白化诊断（2026-10-19）

## 白化：已证实与待证实

**后巷实际曝光增益高出 9.87 倍（3.30 档）和 13.40 倍（3.74 档）。** 相同曝光补偿不能作为同曝光证据。代码自身在 `WindowDirector.cpp:1674` 已指出后巷小天空口在曝光直方图中代表不足。曝光差异足以成为重大混杂因素，但尚不能用它计算白幕中各组件的贡献比例，也不应直接将整个后巷压暗 3.7 档作为最终方案。

其他因素：

- **ExponentialHeightFog**：晴与少云 `FogDensity` 均为 `.008`，没有晴/少云专用减弱；雨乘 1.8，雾天气乘 4。23 m 与 500 m 的视点也不能代表相同雾路径。已记录 `r.VolumetricFog=1`，但捕获 JSON 未导出完整组件高度、HeightFalloff、StartDistance、MaxOpacity 等，需补读后再改。
- **SkyAtmosphere**：晴 Mie `.003996`，少云 `.004152094`，只增加 **3.906%**。少云 Rayleigh 为基值的 `.8984375`，Mie absorption 为 `1.046875`。过去“2.1 倍 Mie 白幕”的注释不是当前仍然使用 2.1 倍的证据。暂不整体削弱 Rayleigh/Mie。
- **云 extinction**：晴天旧低云 global density、fair strength、overcast sheet density 均为 0，实际只保留 **8.2–8.38 km** 卷云，不能把晴天白幕解释成持续低云层。少云 `1.6–8.38 km` 是包含两层的采样范围，不表示其间都填满云密度。未找到独立 horizon extinction 参数；少云远距离消光仍需关云 A/B 判断。
- **Bloom**：两视图均 intensity `.675`、size 4、threshold 1.2。相同 bloom 参数不排除曝光后亮区进入阈值的差异，先保持参数不动。
- **雨玻璃**：晴/少云 `windowRainIntensity=0`，`WindowFrame.cpp:374` 将雨玻璃隐藏；没有证据支持将其认定为当前晴天白幕来源。

## 云的方位、距离与 seed

实际主视角和特写保留了同一个 `OOW_ApprovedOriginKm`：`(-.02, -.208, -.564683914, -.825307250)`。XY 是固定主相机原点，ZW 是水平 forward。`FindSceneActors()` 先缓存这组参数，之后才切 SkyFace。因此不是每张天空图重新生成或重定位了云场。

**卷云：** 当前验收 Blue/group2 单束位于 8.2–8.38 km，shader 前向支撑范围约 12.6–48.6 km，侧向 ±28.8 km。对现有晴天特写指定亮丝 ROI 做背景扣除估计，方向中心约 **yaw −117.29°、仰角 13.31°（500 m 视点）**，偏在后巷天空开口右侧且偏低。此处是手选区域的截图亮度定位，不是原纹理密度重心，不能声称全部 Ci 都在开口外。

ROI 为 x=130…470、y=170…215；红通道权重为 `max(0,R(x,y)-0.5*(R(x,y-10)+R(x,y+10))-4)`。具体像素、公式与来源哈希在 diagnostic.json。原纹理导入记录的旧机 `Ci_LowerAccepted.tga` 本机未找到，但已验收的 uasset 完整存在且哈希正确；这一缺口只阻止直接对源纹理采样，不意味着运行云缺失。

**少云：** ≤4 km 保留旧近景，4–8 km 平滑混合，≥8 km 采用轻量远景。旧云底为 2.04375 km，相机 23 m、距离 4 km 时云底仰角约 **26.8°**，高于天空口上缘 23.68°；更近只会更高。轻量层 1.6–2.5 km 在 8 km 处约 **11.1°～17.2°**，落入狭窄竖缝附近，很多方向被屋顶挡住。故当前主要有机会显示的是 4–8 km 过渡区，而轻量覆盖参数为 `.26`。这说明几何上的可见机会有限，不等于证明每条射线都无云。

当前没有独立天气随机 seed 或 Ci 旋转参数；主要是固定纹理/哈希与世界坐标放置。`OOW_StormOffsetKm` 只影响旧云；`Layout_GlobalTexturePlacement` 会一起移动旧云、新低云和 Ci，不适合单独修正卷云。验收 Ci 分支不使用旧 CirrusCoverage/Density/Scale 参数，仍使用 CirrusStrength。现有截图漂移均为 0，但 world time 不同；下一轮需冻结并记录云时间。

## 推荐的隔离验证与参数方向（尚未实施）

1. **先建立正确对照。** 固定原后巷位置、朝向、FOV、上海地理与太阳、天气、云原点、时间及漂移。使用已有 `-OOWTestFixedExposureEV=<值>`，每种天气内部两图用同一值，并以最终 EyeAdaptationExposure 相等验收。首要“天空特写”直接裁切同一主画面的天空 ROI，保证像素与曝光一致。若另需无遮挡全景，仅在实验会话中隐藏遮挡网格，保持相机和曝光，另行标记其照明/反射局限，不再使用 500 m face 4 当对照。
2. **分别定位白幕。** 晴/少云各采固定曝光基准、仅 `r.VolumetricFog 0`、仅 `r.Fog 0`、仅 `r.VolumetricCloud 0`，每次回到基准后只改一个因素，串行单 UE 实例。必要时才补 `r.SkyAtmosphere 0` 贡献诊断。`OOWTestEmptyCloudReference` 不能当全部云关闭：它清的是旧路径，v2 轻量云仍可能有密度。
3. **若确认雾过强**，在隔离版本试晴/少云密度 `.008 → .006 → .004`，先读实际 HeightFalloff 再决定是否更贴地。高层卷云与近地雾分开调；保留远景空气透视。不要先移动地平线、改变云高或普遍降低天空散射。
4. **只做一束 Ci 布局候选。** 增加实验专用的独立旋转/平移，保留验收纹理、尺度 1.8、高度、密度和单束数量。粗略起点为 yaw **−22°**、沿旋转后的 forward 移近约 **9 km**；这只是由亮丝位置推导的初值，不是通过的参数。用真实不规则 skyMask 的射线覆盖选一个候选，再渲染原版/候选同曝光对照。不要改共享 placement 或全局增加云量。
5. **少云布局另行处理。** 保持 4–8 km 路由与气象语义，选择能穿过开口中上部的少量既有云体方位/相位，评估开口内结构可辨识度和可见覆盖率；不要将 `.26` 参数等同于屏幕 26% 覆盖，也不要为了窗口而填满全天。

上述推荐先交付给用户确认；本轮没有执行参数修改或宽范围天气调整。Houdini v7 的单冠局部试验继续保留，待后巷主视角问题明确后再恢复。
