# 都市场景 2D 对照与 3D 改进

## 场景归属

本记录只对应“都市”场景：宽阔道路、两侧连续街区和远处天际线。后巷使用独立的石板路、雨篷和潮湿材质方向，记录见 `docs/alley-photoreal/COMPARISON.md`。

## 参考图

- 2D 超写实都市参考：[reference-generated.png](./reference-generated.png)
- 生成提示词：[reference-prompt.md](./reference-prompt.md)
- 改造前都市离屏画面：[before-city.png](./before-city.png)

参考图固定了现有窗格、机位和道路构图，只提升窗外城市的材质和空间层次。对照结果分成四项：

1. **建筑表面**：原画面大面积墙体读成单一颜色；现在沿用共享 PBR 材质，并在墙面着色器中加入断续石材分格、矿物污渍、边缘积尘和细颗粒，避免模块化楼体出现整块平面。
2. **街道尺度**：原画面路面只有道路和车道线；城市组新增路缘唇口、铺装接缝和可受风的街树花盆，让道路有连续的近景参照物。
3. **远景层次**：原画面远处只有低对比的楼群；新增多层远景楼体、玻璃幕墙竖向分格、横向楼层线和屋顶设备，并保留 Helsinki LOD2 作为更远层。
4. **日照与空气**：晴天都市使用更高的日间曝光和较低的雾密度，保留远景大气透视，同时让近处墙体和道路保持对比度。墙面分格逻辑与后巷雨景共用，雨天仍由湿润度控制反射。
5. **机位逻辑**：原都市机位落在道路中线附近，容易产生“楼体立在路中央”的错觉。现在相机移到右侧临街建筑一侧，目标仍锁定道路中心和远景；实测画面保留车流、车道线和路口，同时让近侧楼体成为真实的室内观察参照。
