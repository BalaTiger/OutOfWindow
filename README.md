# Out of Window — 虚拟窗景 Demo

一个由本地时间、太阳位置与实时天气驱动的 Electron 桌面窗景原型。Demo 使用 Three.js 混合 3D 渲染：高细节远景负责空间密度，实时 3D 中近景负责光照、阴影与动态。

## 运行

最简单的方式是双击项目根目录中的 `打开Demo.cmd`。

也可以在 PowerShell 中运行：

```powershell
npm install
npm run demo
```

`npm run demo` 直接打开已经构建的桌面 Demo；修改代码后使用 `npm run rebuild-demo` 重新构建。

开发预览：

```powershell
npm run dev
```

## 当前 Demo

- 城市、村庄、山林、海滨四种窗景；
- 城市场景实时车流与建筑窗灯；
- 海面/溪流动画、植被风摆、云层移动；
- 晴、雨、雪、雾天气预览与实时天气模式；
- 经纬度、日期、当地时间驱动太阳高度、方位、色温和光照强度；
- IP 城市级粗定位 + Open-Meteo 实时天气；
- 拖动视差、可折叠控制面板、程序化环境声；
- 透明无边框桌面挂件、系统托盘、鼠标穿透与精简显示模式；
- 实体窗框、窗台与玻璃反光层，景色明确位于窗户内部；
- Poly Haven CC0 高精度 glTF 植被与 HDR 环境光照；
- `MeshPhysicalMaterial`、PMREM 图像照明、ACES 色调映射和软阴影；
- 网络失败时自动使用上海演示数据。

## 数据与隐私

IP 定位只能提供城市/区域级近似位置，不等于用户的物理地址，更不能定位门牌。Demo 不保存 IP、坐标或天气记录；坐标仅在当前进程中用于天气与太阳计算。

当前使用：

- [ipwho.is](https://ipwhois.io/documentation) 获取免密钥城市级坐标；
- [Open-Meteo](https://open-meteo.com/en/docs) 获取当前天气。

生产版应增加首次启动授权、服务隐私政策、请求缓存、API 配额监控，以及手动城市选择。

## 产品化路线

1. 用模块化 glTF 资产替换程序化几何，增加 LOD、实例化植被和烘焙 AO。
2. 增加 CSM 级联阴影、体积云、SSR/屏幕空间反射、湿润度材质和真实天空散射。
3. 引入季节、空气质量、月相与能见度数据；天气在 10–20 分钟内平滑过渡。
4. 增加桌面置底、鼠标穿透、多显示器、开机启动、托盘菜单和帧率/功耗档。
5. 场景包下载与校验，基础程序保持轻量，资源按需安装。

## 3D 免费资产策略

生产阶段优先筛选 CC0 / CC BY 且可追溯来源的资源：Poly Haven（HDRI、材质、部分模型）、ambientCG（PBR 材质）、Kenney（低模与原型资产）。每个第三方资产都应在 `THIRD_PARTY_ASSETS.md` 登记来源、作者、许可证、版本和修改记录；不要仅凭搜索结果中的“free”描述直接打包发布。

## Demo 限制

- 当前远景包含烘焙光影，因此极端时间切换依靠实时色彩分级近似；中近景光照与阴影是真实时计算。
- 当前只有山林预设完成了第一批高精度模型替换；城市、村庄和海滨近景仍需继续资产化。
- IP 定位在 VPN、企业网络和移动网络下可能偏离实际城市。
- 环境声是无素材的程序化噪声占位，正式版应换成可追溯授权的分层声景。
